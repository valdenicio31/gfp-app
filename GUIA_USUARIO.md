# GFP App — Guia Rápido

## Começar

1. Abra o aplicativo.
2. Clique em **Novo lançamento**.
3. Escolha receita ou despesa.
4. Informe descrição, valor, data e categoria.
5. Clique em **Salvar lançamento**.

## Planejamento

Use **Orçamento mensal** para definir o limite de despesas do mês. O painel mostrará o percentual utilizado.

## Filtros

Filtre lançamentos por mês, tipo, categoria ou descrição. Os indicadores e o gráfico de categorias acompanham os filtros aplicados.

## Segurança dos dados

- Os dados ficam no navegador do aparelho.
- Use **Backup JSON** regularmente.
- Use **Exportar CSV** para análise em planilhas.
- Limpar dados do navegador pode apagar os lançamentos locais.

## Restaurar

Clique em **Importar** e selecione um backup JSON ou um CSV exportado pelo GFP.
